## The entry

`main.py` (Python standard library only) writes one line — a message to a boss
where autocorrect turns "annual review" into something far more awkward — to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

The output path can be overridden with `ENTRY_OUTPUT`, or a directory with
`OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`.
